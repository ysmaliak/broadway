Broadway 0.3

New in this version

  • Open source. Broadway's code is now public under the MIT License at github.com/ysmaliak/broadway, for anyone to read, build and change. Help › Broadway on GitHub opens it.
  • Live Folders in your order. Drag a row inside a Live Folder and it stays where you drop it, through every refresh. A stack of pull requests moves as one. Restore Automatic Order in the folder's menu brings back the order it had.
  • Merged stacks. When you merge a pull request in a stack, the ones below it turn to Merged with it and leave together. The word Merged now rises into place in the mark's colour.
  • Address. In the sidebar's address a subdomain is softer than the site, so the site stands out. When room is short the subdomains give way first and the site stays whole.
  • Glass buttons. Glass buttons swell and light under a press, as the system's own do. The video player's button now animates between play and pause.
  • About Broadway. The About window has a new look, in Broadway's own grid and line.
  • Small things. The lines that appear when a list scrolls fade in and out. Split View and the mini player are sharp on a display that is not Retina. The Claude and ChatGPT cards show a letter where each company's logo was.

Requires macOS 27 on a Mac with Apple silicon.
