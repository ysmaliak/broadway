Broadway 0.2.4

New in this version

  • Downloads. A file now arrives when a site opens a new tab or window as it starts the download, sends the page you were on to the file, or opens the file after a countdown. The pop-up blocker used to stop these. It still stops the pages it is there for.
  • Tab titles. Titles at rest in the sidebar are a touch softer.

Requires macOS 27 on a Mac with Apple silicon.
