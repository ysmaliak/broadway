Broadway 0.4.4

New in this version

  • Asking where to save no longer stops the browser. In Settings, under General, Save downloads to can be a folder of your choice or Ask Each Time. With Ask Each Time, the question is now a sheet on the window the download started in, so your other windows keep working. Before, it was a panel that held up every window until you answered. Two downloads ask one after the other.
  • The sheet opens where you saved last. Each space remembers the folder you picked last, and a private window records none. The file's whole name shows, with its ending.

Fixed in this version

  • Saving over a file with the same name replaces it, and the old file goes to the Trash. Before, the download failed.
  • A file an agent downloads into your downloads folder no longer asks you where to put it.
  • The Downloads page says that Broadway asks where to save each file when it does, and Other… in Settings is a sheet on the Settings window.

Requires macOS 27 on a Mac with Apple silicon.
