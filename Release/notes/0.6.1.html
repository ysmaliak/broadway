Broadway 0.6.1

Fixed and improved

  • Updates in the sidebar. When a new version is out, the sidebar says Update Available with an Install button. Install checks for the newest version right then, so it never installs an older one that was downloaded earlier. Then it downloads with a progress line and a percent, installs and reopens Broadway.
  • Check for Updates… and Settings › General show the same steps in Broadway's own words instead of a separate update window. While an update waits, Check for Updates… still looks for a newer one.

Requires macOS 27 on a Mac with Apple silicon.
