Broadway 0.4.1

New in this version

  • Claude Code and Codex are set up when you turn agents on. Turning on Let agents use Broadway now adds Broadway's skill and its small hook to Claude Code and Codex, so a finished agent reads Finished the moment its turn ends. You no longer run broadway setup claude codex yourself. If agents were already on, this happens once when 0.4.1 first opens. It also puts the broadway command in ~/.local/bin when none is there, and never moves one that is. broadway remove takes it all out again, and Broadway does not put it back until you turn agents off and on. Codex may ask you to approve the new hook once in /hooks.

Requires macOS 27 on a Mac with Apple silicon.
