Broadway 0.4.2

Fixed in this version

  • Stack numbers on pull requests keep up. In a Live Folder of GitHub pull requests, a pull request that joined a stack could stay without its stack number, and the rest of the stack kept the old count. Broadway now looks again when a pull request sits on another one's branch, when one member of a stack changes, when you open a pull request's page, and every half hour.

Requires macOS 27 on a Mac with Apple silicon.
