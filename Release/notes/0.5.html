Broadway 0.5

New in this version

  • Ask about the page in front. ⌘J opens a line at the foot of the page. Ask a question and the answer comes from the agent you picked in Settings › Agents. You can follow up, put an answer into the box you were typing in, add another tab, a picture or a file, and ask the other agent for a second answer. A question typed in the address field offers Ask as well.
  • A chat beside the page. View › Show Chat, ⌃⌘A, opens a column that answers about the page in front and keeps the conversation. Return steers an answer that is still coming, ⌘Return queues the next question and Escape stops. View › Chats lists your chats, and each can be renamed, pinned or deleted with Undo.
  • The chat can do things for you. While Let agents use Broadway is on and your agent is Claude Code or Codex, a chat can click, type and open tabs, under the same approvals as any agent task. If a page has text written for an AI, the chat asks you before it does anything there. With agents off, a chat only reads and answers.
  • Improve, fix, translate, summarize, explain. Select words on a page and find these in the right-click menu and in Edit. The agent you picked does the work and cannot browse or act while it does.
  • What stays on this Mac. In a private window only the model on this Mac answers, and a private chat is never kept. When This Mac is your pick in Settings, nothing is sent to Claude Code or Codex. Password, card and code boxes are never read.
  • Live folders you can rely on. A folder changes only on a read that went well, so a failed or half-loaded read never empties it. It says why when it could not read: you are offline, the site is limiting requests, or the page could not be understood. It shows how old its list is once that matters, and a last row such as More on GitHub when there is more than it shows. Broadway closes a tab of a live folder only if it opened that tab and you are not using it, and Reopen Closed Tab brings it back.
  • Sites ask before they send a file. A file a site starts sending by itself waits on a card until you allow it. A file from a secure page that arrives over a plain connection asks every time. The Dock icon shows a bar while downloads are under way.
  • Leave this page? A page with unsaved changes asks on its own tab before you reload it, go elsewhere, close its tab or window, or quit. One Stay keeps the window open and calls a quit off.
  • Back to where a link came from. Back on the first page of a tab a link opened closes that tab and shows the tab it came from. Reopen Closed Tab brings it back.
  • Split View. ⌥↩ in the address field opens what you typed or picked beside the page on screen. Two pages side by side can be pinned as one square among your pins, and pinning or unpinning is one Undo step.
  • Calls and meetings. A call joined from Broadway is heard at once, before you click anything in it. Pages you open from a call gather with it in a folder named after the meeting. While somebody presents, the floating call window takes the shared screen's shape and shows it alone. The call window can be made larger by its edge and remembers its size. A reminder with many guests shows how many there are.
  • Sign-ins that last. Restarting Broadway no longer signs you out of sites that keep you signed in only until the browser quits. An empty new password box offers Use Strong Password and keeps the login. A password that is already kept no longer asks to be saved again.
  • Certificates. A site that asks for a certificate of your own gets the system's chooser over its tab. Continue Anyway on a bad certificate now holds only for that site in that space, for a week, or a month on your local network.
  • Pages that misbehave. A page that stops answering is ended and loaded again when you reach for it. A page that takes more than half the Mac's memory is stopped within seconds and says so on its tab. A page that failed for want of the network loads again when the network is back. The page a failed load shows is plainer and reads the same in every space.
  • Drag a tab out of its window. A dragged tab shows a picture of its page under the pointer and can be put down at a chosen place in another window's sidebar.
  • Hints. Broadway says the faster way once, in a short line, when it sees you take the long way: ⌘W, ⇧⌘T, drag for Split View, Copy Clean Link, ⌘G. One a day at most, and Settings › General has a switch for it.
  • New in the menus. Merge All Windows and Keep Window on Top in Window. Use Selection for Find and Copy Link to Highlight in Edit: the copied address opens the page scrolled to the words you selected. Mute Other Tabs in a tab's menu. Open at Login in the Broadway menu.
  • Handoff. The page in front is offered to your other Apple devices, and a page handed to this Mac opens in Broadway. Never from a private window.
  • Hooks. A small program of your own can decide where a link from another app opens, where a finished download goes and how a site's request for the camera, microphone, location or notifications is answered, or run every few minutes. You add one in Settings › Agents › Hooks, and only you can.
  • For agents. An agent can ask you one question with choices, which is never an approval. It can read a whole table or long list as rows, and check a page for accessibility problems, loading times and an element's styles. Spaces, folders, bookmarks, live folders and settings can be reached over MCP under the same permissions as the command. Setup also covers Cursor, opencode and Gemini CLI, and an agent you install later is set up the next time Broadway opens.
  • When a load or a download fails. Broadway keeps a short log on this Mac of what kind of failure it was, with no address and no file name in it and nothing from a private window. The command broadway doctor prints its last lines.

Fixed in this version

  • Small keys on floating bars, the signs in the address pill and the mini player's line take a click over a larger area, drawn as before.
  • Settings › Agents no longer calls it a fault when Cursor, opencode or Gemini CLI has no Broadway skill yet.
  • When This Mac is your pick and it has no model, Broadway says so and no longer falls back to another agent.

Requires macOS 27 on a Mac with Apple silicon.
