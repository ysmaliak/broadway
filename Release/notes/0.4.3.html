Broadway 0.4.3

Fixed in this version

  • Stack numbers on pull requests catch up sooner. When a Live Folder has more pull requests to look at than one pass has time for, Broadway now starts with the ones that look wrong and the one whose page you just opened, then takes the rest oldest first. Before, a pull request near the bottom of a long folder could wait a long time, or be left out while the window was out of view.

Requires macOS 27 on a Mac with Apple silicon.
