Broadway 0.4

New in this version

  • Agents use Broadway far better. The broadway command and the MCP server were rebuilt for the agents that use them. A click or a typed line now answers with what changed on the page, so an agent no longer looks again after every step. Going to a page answers with a short look at it. Agents can name a button by its words, do several known steps in one call, and write a short script with loops when a task needs one.
  • An agent's page stays in its tab. A page an agent works on could show at the edge of your screen. It now lives only in its tab, and still runs at full speed there. A page can no longer open a menu or go full screen on your display while nobody is looking at its tab.
  • Tabs an agent can keep tidy. Each agent has its own tabs and a current one. Opening an address says how many tabs the agent has and whether that address is already open. Windows a page opens stay with the agent that caused them. An agent can close its other tabs in one step, and a tab with an unsent form or a running download is kept. An agent that comes back after saying it was done finds its tabs again.
  • When an agent needs you. A page that wants a password, a code or a captcha says so, and an agent can hand you its tab with a reason and wait. A question is asked once: a repeated step joins the question already on the card. Signing in asks with words of its own, and filling a saved sign-in says what it fills.
  • Safer by default. Giving a site access to an account now always asks. Recovery phrases and private keys are treated like passwords, and what sits in a password box never appears in a question. Page text that reaches an agent over MCP stays marked as website content.
  • An agent that has finished looks finished. When an agent's turn ends, its card says Finished with the last thing it did, and the Agents header counts it as done. A quiet agent reads Idle after two minutes, and one between steps reads Thinking. Running broadway setup claude codex once adds a small hook to Claude Code and Codex so Broadway hears the moment a turn ends, and broadway remove takes it out again.
  • Agents in the sidebar. The Agents section starts folded and opens only when you press it. Each agent's face has an expression for what it is doing, with a gentle idle motion. Agent tab rows are laid out like your other tabs.
  • Closing a tab takes you where you expect. Close a new tab straight away and you are back on the tab you came from. Close a link you opened and you return to its page. Links opened behind close onto the next one, a tab in a folder keeps you in that folder, and a window a page opens sits right after its page. Closing never lands you on an agent's tab.
  • Live Folders by status. A Linear folder chooses which statuses it shows, in its settings and in its menu. Backlog is off to begin with, so planned and started work has the room.
  • Small things. The Join button on a meeting card is green whichever app is in front. Agents that were running during an update carry on with the new version.

Requires macOS 27 on a Mac with Apple silicon.
